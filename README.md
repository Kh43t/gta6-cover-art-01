**Vice Coast Cover Studio** — a free offline web app that turns any photo and caption into GTA-style multi-panel cover art: six poster layouts, five Vice City sunset/neon colour grades, per-panel crop and positioning, bold genre lettering with a sunset title band, and one-click export in the common post sizes (1080×1080, 1080×1350, 1920×1080). Photos never leave the machine. All art, lettering and frames are drawn by the app itself — no Rockstar logos, artwork or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick a layout, drop in your photos, write a caption, and export the PNG.
